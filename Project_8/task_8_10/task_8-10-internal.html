Internal CSS

CSS помогает оформлять HTML-страницу и делать её красивее.

Internal CSS пишется внутри тега style в head.

Такой способ удобен для учебных заданий и небольших страниц.

  • Цвет текста
  • Фон элемента
  • Отступы и рамки
